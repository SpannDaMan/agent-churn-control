# Release Checklist

- [ ] Public metadata, developer, URLs, version, and assets match the release.
- [ ] Copy benchmark and benchmark-application gate pass.
- [ ] Targeted adoption/trust review has no unresolved P0/P1 or material P2.
- [ ] Unit tests and all fixture cases pass.
- [ ] Sample receipt and package integrity pass.
- [ ] Release validator reports one frozen candidate hash.
- [ ] Submission ZIP matches the frozen hash and contains no generated residue.
- [ ] GitHub feature branch, PR, mergeability, review, and CI pass.
- [ ] Public v0.1.2 tag and release target the merged commit.
- [ ] Private vulnerability reporting is enabled.
- [ ] Clean Codex marketplace installation passes.
- [ ] OpenAI skills-only upload, skill validation, attestations, approval, publication, and public readback match the prepared packet.
- [ ] Publication receipt and setup-completion proof are written.
