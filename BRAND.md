# Agent Churn Control Brand

## Identity Lock

- Product name: Agent Churn Control
- Public developer: Orbral
- Repository owner: SpannDaMan
- Category: Developer Tools
- Core line: Stop duplicate agent work.
- Brand thesis: Keep agents moving forward by reusing accepted evidence instead of repeating equivalent work.

## Audience

Primary users are agent builders, Codex power users, plugin maintainers, and small platform teams that repeatedly run tests, reviews, retries, tool calls, or multi-agent packets under limited time or model allowance.

Their job is not “use fewer tokens at any cost.” Their job is to preserve capacity without skipping changed work, final verification, or safety gates.

## Positioning

Agent Churn Control is a local, skills-only guard for duplicate work. It sits before an action, computes a deterministic identity, and returns one of four bounded outcomes: bypass, observe, enforce, or promotion gate.

It is not a model router, gateway, scheduler, hosted observability product, usage dashboard, or universal optimizer. It does not promise a percentage reduction in tokens, cost, or latency.

## Proof Objects

- deterministic content-free receipts;
- typed single-use invalidation;
- cross-process state serialization;
- versioned fixture corpus;
- package integrity verification;
- public tests and release receipts.

Every public efficiency claim must point to one of these proof objects or remain explicitly hypothetical. Numeric savings require comparable basis receipts.

## Voice

- Lead with the job and result.
- Use ordinary builder language: duplicate work, accepted evidence, changed work, final verification.
- Be direct, calm, and technically specific.
- Prefer “helps preserve capacity” over “saves tokens.”
- Prefer “blocks only the duplicate local action” over “stops the agent.”

## Do

- Say: Stop duplicate agent work.
- Say: Reuse accepted evidence without blocking changed work.
- Say: Local, no account, no API key, no telemetry.
- Say: Rate-limit signals remain advisory.
- Show receipts, decisions, and proof.

## Do Not

- Do not promise guaranteed savings.
- Do not claim a causal Sol or Codex rate-limit defect.
- Do not imply the plugin controls overall task completion.
- Do not use fear-based “burning money” language.
- Do not call synthetic focus groups customer validation.
- Do not imply OpenAI endorsement or verification.

## Visual Meaning

The mark represents a repeated loop interrupted by a clean forward path. A navy-to-electric-blue loop carries continuity and technical trust; a cyan break/check indicates preserved progress. The symbol must remain simple at small icon sizes and must not use coins, flames, speedometers, generic robots, brains, hourglasses, or warning triangles.

## Rights and Public Setup

The visual identity must be original and generated or rebuilt for Orbral. Do not incorporate third-party logos, product UI, copyrighted mascots, or named model marks. Public assets may use the Agent Smith Palette family language but must be distinct from other plugin marks.

Public publication is approved for Agent Churn Control only. Paid promotion, social launch posts, Sponsors/payment setup, permissions/scopes, and unrelated products remain outside this brand packet.

## Public Support Boundary

Use GitHub Issues for reproducible non-sensitive defects, Discussions only if later enabled, and private vulnerability reporting for security issues. Never ask users to post prompts, secrets, private source content, or raw receipts containing sensitive identifiers.
