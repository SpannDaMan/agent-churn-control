# Support

Support is best-effort and focused on installation, event validation, work identity, receipt verification, evidence reuse, typed invalidation, and documentation defects.

- Use a GitHub bug report for reproducible non-sensitive defects.
- Use a feature request for a bounded product need.
- Use private vulnerability reporting for security issues.
- Remove prompts, secrets, private paths, customer data, and raw sensitive identifiers before sharing fixtures or receipts.

Include the plugin version, operating system, Python version, command, expected result, actual result, and a minimal synthetic event when reporting a bug.
