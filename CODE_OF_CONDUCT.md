# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Assume good faith, criticize ideas and code rather than people, protect private information, and make room for different experience levels.

Unacceptable behavior includes harassment, discrimination, threats, sexualized conduct, deliberate disruption, publishing another person's private information, or using project channels for spam.

## Enforcement

Report sensitive conduct concerns through a private maintainer channel or GitHub's private security/contact route when appropriate. Maintainers may edit or remove contributions and restrict participation to protect a safe, productive project.

This project follows the spirit of the Contributor Covenant while keeping the contact path private until a dedicated public address is established.
